Клиентский Fabric-мод для Minecraft **1.21.11**: выделяйте блоки Shift + двойным ПКМ и стройте между ними разноцветный граф с подписями расстояний прямо в мире. Удобно для строительства, планирования и декора.

## Возможности

- **Shift + двойной ПКМ** по блоку — добавить его в выделение; повторный Shift + двойной ПКМ по выделенному блоку — убрать. Без Shift клики работают как обычно, без задержки.
- **Режим «Два ближайших»** (по умолчанию) — каждый выделенный блок соединяется с ближайшими выделенными блоками, но от одного блока может отходить **не более двух автоматических линий**. Пары добавляются от самых коротких к длинным, поэтому ближайшие соседи получают связь первыми. Ручные связи (ПКМ + Alt/Shift) в этот лимит не входят и рисуются дополнительно. Для связного графа используйте «Ближайшие блоки».
- **Режим «Ближайшие блоки»** — линии образуют минимальное связующее дерево, соединяющее все выделенные блоки.
- **Ручные связи**: нажмите **Alt + ПКМ** (по умолчанию) по выделенному блоку, затем **Alt + ПКМ** по другому выделенному блоку — они соединятся принудительно, даже если не являются ближайшими. В настройках можно переключить клавишу связи на **Shift**: тогда одиночный Shift+ПКМ по выделенному блоку создаёт связь, а быстрый второй Shift+ПКМ по нему убирает блок.
- **Режим «Все пары»** — каждый выделенный блок соединяется с каждым другим.
- **Shift + Backspace** — очистить весь граф (во всех режимах).
- На каждой линии показывается расстояние между **центрами блоков**, округлённое **до сотых**; близкие подписи автоматически разводятся, чтобы не перекрываться. Подписи показываются автоматически для линий выбранного режима и **не зависят от Alt/Shift**.
- Линии начинаются от центра той грани блока, по которой кликнули, а не от центра блока. Если у соседних блоков эти точки совпадают, соединитель рисуется чуть выше блоков, чтобы линия не пропадала.
- Яркие RGB-цвета блоков и линий, радужные или фиксированные цифры.
- Настройка размера, высоты, жирности, обводки и фона цифр.
- Встроенный экран настроек (**K**) с сохранением/загрузкой пресета и сбросом. Mod Menu и Cloth Config не нужны.

## Требования

| Компонент | Версия |
|---|---|
| Minecraft | 1.21.11 |
| Fabric Loader | 0.19.5+ |
| Fabric API | 0.141.6+1.21.11 |
| Java | 21+ |

Других модов не требуется: экран настроек построен на ванильных виджетах.

## Сборка

```powershell
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-25.0.4.101-hotspot"
.\gradlew build
```

Готовый мод: `build/libs/blockgraph-1.0.0.jar`.

Положить в `.minecraft/mods` (или в папку модов Prism-инстанса) вместе с Fabric API.

## Запуск dev-клиента

```powershell
.\gradlew runClient
```

В IntelliJ IDEA достаточно запустить `runClient`: Mod Menu и Cloth Config больше не подключаются, в dev-клиенте загружаются только Fabric API и сам мод.

## Управление

| Действие | Клавиши |
|---|---|
| Добавить/убрать блок | Shift + двойной ПКМ |
| Начать/завершить ручную связь | Alt + ПКМ по выделенному блоку (по умолчанию; можно выбрать Shift) |
| Открыть настройки | K (по умолчанию, меняется в управлении) |
| Очистить весь граф | Shift + Backspace |

Выделение работает только с зажатым Shift. Без Shift правые клики проходят в игру сразу, поэтому обычная установка блоков и открытие контейнеров не задерживаются. С Shift мод на 250 мс задерживает первый клик, чтобы успеть распознать второй: если второго клика нет, одиночное действие (установка блока, открытие сундука и т. п.) выполняется после этой задержки. Задержку можно отключить в настройках, но тогда двойной клик сработает, только если первый клик не изменил цель.

## Настройки (клавиша K)

Экран настроек открывается клавишей **K** (по умолчанию). Настройки разбиты на страницы, переключение — кнопками `<` и `>`. Подсказки появляются при наведении на название или значение и остаются короткими.

**Основное**

- Режим графа: «Два ближайших блока» / «Ближайшие блоки» / «Все пары».
- Клавиша связи: Alt (по умолчанию) или Shift. Выделение всегда Shift + двойной ПКМ; если выбрана связь на Shift, одиночный Shift+ПКМ по выделенному блоку создаёт связь, а быстрый второй Shift+ПКМ убирает блок.
- Линии, подписи, подсветка блоков. Подписи расстояний не зависят от клавиши связи.
- Радужные цвета или фиксированный цвет.
- Толщина линий (1–16 px) и лимит блоков.
- Задержка Shift+ПКМ для распознавания двойного клика.

**Подписи**

- Размер текста.
- Высота подписи над линией.
- Жирность цифр и толщина обводки.
- Радужный текст или свой цвет.
- Фон подписи.

**Кнопки в левом нижнем углу**

- **Сохранить пресет** — записывает текущие настройки в `config/blockgraph-preset.json`.
- **Загрузить пресет** — применяет сохранённый пресет.
- **Сбросить настройки** — возвращает значения по умолчанию.

Файл настроек: `config/blockgraph.json`.

## Мультиплеер

Мод **полностью клиентский**: в `fabric.mod.json` указано `"environment": "client"`, серверных точек входа и сетевого кода нет. Он работает на любом сервере, но каждый игрок видит только свои выделения.

Показывать выделения других игроков на ванильном сервере нельзя без серверной части: клиенты Minecraft не обмениваются данными напрямую, а сервер передаёт только свои пакеты. Для общего выделения нужен один из вариантов:

- серверный мод/плагин-ретранслятор (клиент остаётся клиентским, но на сервер нужно установить дополнительный компонент);
- внешний relay-сервис;
- отдельная настройка «показывать выделения других игроков» после появления такого ретранслятора.

В текущей версии этих компонентов нет, поэтому настройка просмотра чужих выделений не добавлялась: она была бы нерабочей.

## Как это работает

- `BlockGraphClient` — входная точка клиента: распознавание Shift + двойного ПКМ, ручные связи, клавиша очистки.
- `SelectionManager` — хранит выделенные блоки, их грани, принудительные связи и строит рёбра (два ближайших блока, дерево ближайших блоков или полный граф).
- `BlockGraphRenderer` — рисует рамки, линии и подписи через `WorldRenderEvents.AFTER_ENTITIES`.
- `config/` — конфиг (Gson), встроенный ванильный экран настроек и пресеты.
